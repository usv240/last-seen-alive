### What was built

**All six Parallel surfaces, each doing work the product actually needs.** Three are agent tools,
because deciding *when* to research is a judgement call. Three are called by deterministic code,
because each exists to check or outlast the model's own work — a system that both gathers
evidence and rules on whether that evidence holds up can talk itself into either answer.

| Surface | Role | Why this way |
|---|---|---|
| Search | Every open-web fact | Content-recycling domains excluded at source-policy level, so the gate's "three independent domains" threshold cannot be satisfied by three mirrors of one plot summary. Long excerpts so a verbatim intertitle can be matched again later. |
| Task | Holdings and alternate titles | JSON output schema instead of prose; a source policy points this one surface at library/archive/`.gov`/`.edu`, while Search deliberately stays open to the whole web. |
| **FindAll** | Names the catalogues | This product may never write "last surviving copy". The only permitted sentence names the catalogues searched — and FindAll produces that list, so the safety rule now has a mechanism behind it rather than a prompt instruction. |
| **Extract** | Live citation audit | Re-opens every page a decisive claim cites and looks for the quotation in the live document. The difference between "a search snippet contained this" and "the page still says this". A citation that fails is shown to the archivist and refused by the gate. |
| **Task Group** | Adversarial fan-out | One independent researcher per candidate, none of which has seen the others, each asked only to disprove its own candidate. The Skeptic agent, working in one context window, inherits its own earlier conclusions; these runs cannot. |
| **Monitor** | Cold-case watch | An abstention is right today and wrong forever — archives digitise continuously. Turns "we cannot identify it" into a standing weekly query on the strings visible in the frame. |

**Product surface.** Four pages: `/`, `/presets`, `/api`, `/stack`. A live sponsor-stack ribbon on
every one of them, reading from `GET /v1/stack` so an unavailable service shows as unavailable
everywhere at once. Ten demo fragments are watchable inline with range requests and downloadable,
carrying their published SHA-256 as a response header; held-out media returns 423 on every path.

**Bring your own data.** `POST /v1/investigate` takes a caller's file, validated before any model
or partner call, held in memory only, with the data-flow consequences stated on the form itself.

**As an API.** Stateless HMAC-signed keys that verify on every instance; key-gated investigation
endpoints; a stable `{ok,error:{code,message,fix,docs}}` contract; and a playground at `/api`
that mints a key and fires a real request from the browser. The site has no privileged internal
path — every button calls the same public endpoints a third party would.

**Safety made real.** `find_prohibited_language` now runs over every agent output on every
investigation, and violations are surfaced in the dossier as flagged sentences rather than
published as findings. A source that fails the Extract audit cannot contribute a threshold —
`tests/test_parallel_surfaces.py` asserts exactly that.

### Test and lint state

`ruff check .` clean, 60 tests passing, no network or credentials required. The suite proves all
six surfaces fail closed with the credential removed, that a key minted by one instance
authenticates on another, that published hashes match the bytes actually served, that held-out
media is never served, and that the public preset listing does not quote the discriminating
evidence the workflow is supposed to find for itself.

## 4. The one blocker, and exactly how to clear it

**No Parallel credential exists.** There is no `last-seen-alive-parallel-api-key` secret in
`agentic-fleet-2026`, and the live Cloud Run service carries no `PARALLEL_API_KEY`.

Owner action, in order:

1. Obtain a key at https://platform.parallel.ai (redeem any hackathon credit from the Devpost
   Parallel resources page first).
2. Create Secret Manager secret **`last-seen-alive-parallel-api-key`** in `agentic-fleet-2026`
   with the key as its first version. Do not paste it into chat, a commit, a command argument, a
   screenshot or the video.
3. Grant `lsa-runtime@agentic-fleet-2026.iam.gserviceaccount.com` the
   `roles/secretmanager.secretAccessor` role on that secret.
4. Run `infra/deploy.sh`. It detects the secret, binds it, and verifies `/health/integrations`
   before reporting success. Without the secret it deploys anyway and says so — the degraded state
   is correct and visible rather than a failed deploy leaving a stale revision up.
5. Run all five development fragments through the live workflow. Fix only development failures.
6. Freeze with a signed `eval-freeze-*` tag, then run the five holdouts exactly once and publish
   every miss.
7. Record the demo video only after live Parallel health passes.

Until step 4 completes, the honest description of this project is: *implemented against all six
Parallel surfaces, verified fail-closed, never executed.* Nothing in this repository claims
otherwise, and `/health/integrations`, `/v1/stack` and the ribbon on every page report the
integration as unavailable.

### Defects found and fixed

| # | Finding | Severity | Where |

| 15 | `run_eval` resolved corpus files by filename stem, but the files are `fragment_D01.mp4` for case `D01`, and the answer key is a **list** keyed by `case_id` while the harness wants a mapping — with `holdout` vs `held-out` as a third mismatch. ### De-risking the first live run

The six Parallel surfaces had never executed, so their **parameter shapes were
the largest untested risk in the project** — a mis-nested `source_policy` or a
wrongly typed `task_spec` would have failed on the first live call, which is also
the call that matters most.

`tests/test_parallel_wire_contract.py` now intercepts the SDK's HTTP transport
and asserts on the JSON body that would actually be sent, for every surface. It
needs no credential and no network. It already caught one real distinction worth
writing down: Search nests `source_policy` inside `advanced_settings` while Task
puts it at the top level, and Python accepts either silently.

### Verification added

- `scripts/verify_live.py` — **72 checks against the deployed service**, runnable
  by anyone: `python scripts/verify_live.py`. It checks behaviour rather than
  status codes, including that the bytes served for a demo fragment hash to the
  value the manifest publishes.
- CI simulated in a clean virtualenv from the pinned lock: ruff clean, 85 tests.
- Full transitive dependency tree audited: 111 packages, **no prohibited AI or
  agent framework**, and the only AI SDKs present are `google-adk`,
  `google-genai`, `google-cloud-aiplatform` and `parallel-web`.
- Confirmed the application never fetches a URL itself. There is no `httpx`,
  `requests` or `urllib` call anywhere in `app/` or `agentic_core/` — every
  open-web access goes through the Parallel SDK, which is what makes "Parallel is
  the only open-web path" a structural fact rather than a claim.
