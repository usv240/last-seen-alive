THE CONTRACT

      
What you can rely on.

      

        

          
An abstention is a 200

          
“I could not identify this” is a correct, useful answer, not an error. Check meta.verdict, which is one of probable, candidates or abstain. The API can never return a confirmed identity: human_approved is a gate threshold only an archivist can satisfy, outside this API.

        

        

          
Errors say how to fix themselves

          
Every failure returns {ok:false, error:{code, message, fix, docs}} with a stable machine-readable code. A missing partner credential is a 503, never a degraded guess: this service will stop before it answers from model memory.

        

        

          
Provenance is in the payload

          
Each source carries verified (the excerpt matched what Parallel returned) and live_verified (the quotation is still on the page today). A source that fails either is shown to you and refused by the gate. evidence.rejected_citations lists everything discarded and why.

        

        

          
Limits, stated honestly

          
2,000 calls a day for a judge key, 500 for an evaluation key. That counter lives in each instance's memory, so with several instances the real ceiling is higher, and we would rather say that than imply a distributed quota we do not have. Investigations took 61 to 444 seconds (median 304) across 27 runs, with one 95-minute outlier; nothing is queued or cached, so every call pays that in full. The full distribution is at /v1/eval/stability.
