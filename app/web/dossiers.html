REAL OUTPUT, INCLUDING THE FAILURES

What this product actually produced, without waiting for it.

An investigation takes minutes. These are complete responses captured from real runs of this deployed service against the public demo fragments: every claim, every citation, which citations survived the live audit, and which of the gate's thresholds passed.

Nothing here is curated. No run was repeated to get a better result, and the abstentions are published beside the successes because an abstention is a correct outcome when the evidence does not support an identity. Held-out fragments are never captured.

Two things to know before you read these

The same fragment often does not give the same verdict

This pipeline is not deterministic, and the instability is larger than we first reported. Five agents make live web calls against a web that changes, and Gemini is sampled rather than replayed. Over 28 recorded runs of these five fragments, only one case gave the same verdict every time. D02 returned four different leading candidates in four runs; the dossier below is the one where it answered Bray Studios Inc., the studio, not the film. D04 returned the same wrong film in three of four runs.

That is published rather than smoothed over, and it qualifies the headline numbers directly: a single pass is a sample, not a measurement. Across all 28 runs there were 9 false-confident identifications, not the zero one pass recorded. The full study is at /v1/eval/stability, including the run that took 95 minutes.

These dossiers were captured before the two defects were fixed, and they are kept that way on purpose: the D02 dossier below shows the candidate slot holding a studio, which is exactly the defect app/works.py now rejects. Each dossier reports the gate it was actually scored under. What changed afterwards, and what did not, is at /v1/eval/fix-comparison: the non-films are gone; the wrong films are not.

One thing did not move. No run, in 28, ever reached probable, because that threshold needs a human, and the API cannot supply one. The verdict boundary between candidates and abstain wobbles; the guarantee that the system will not assert an identity on its own does not.

An abstention is not a failure to answer

It is a refusal to answer without evidence. On D04 the research worked (thirteen domains, the signage correctly transcribed), and then ten citations were rejected because the quoted text could not be re-found on the live page. No decisive claim survived, so the system abstained on a fragment whose answer key names a real film.

That is a real cost, kept on purpose, though it is not a guarantee: on other runs the same fragment produced Un coin de Paris (1900), which is the wrong film. The strictness reduces confident errors; it does not eliminate them, and the study says by how little.
