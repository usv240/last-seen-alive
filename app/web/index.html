LAST SEEN ALIVE

ARCHIVAL IDENTIFICATION TRIAGE

Before an unidentified reel is discarded, investigate what it might be.

Last Seen Alive finds clues inside a nameless film fragment, searches historical records, challenges its own candidates, and shows an archivist exactly what the evidence can—and cannot—establish.

A four-role Google ADK workflow extracts typed multimodal clues, searches through Parallel, preserves claim-level provenance, attempts falsification, then passes structured evidence to a pure deterministic gate with mandatory human approval.

WHO THIS IS FOR

An archivist triaging unidentified material.

The tool does the broad, repetitive investigation and hands over a dossier. The archivist—not the model—decides whether the evidence is strong enough to act on.

The gate requires three independent domains, two distinct clue families, temporal and entity compatibility, no unresolved contradiction, cited decisive claims, and explicit human approval.

HOW IT WORKS

Four roles. One gate. No hidden verdict.

  1. 01

    Visual Examiner

    Writes down the words and physical clues visible in the fragment.

    Gemini multimodal emits a typed clue set; verbatim intertitles remain verbatim.

  2. 02

    Phrase Hunter

    Searches old publications using the rarest exact words.

    Parallel Search API receives two to five literal, diverse probes and returns cited excerpts.

  3. 03

    Holdings Researcher

    Checks alternate titles and named archive catalogues.

    Parallel Task API performs multi-hop research across title, studio, performer, region, and holdings.

  4. 04

    Skeptic

    Tries to prove each candidate wrong.

    Gemini directs fresh Parallel searches for date, entity, and attribution contradictions.

  5. 05

    Evidence gate · deterministic

    Code checks every rule. An archivist must still approve.

    A pure Python function exposes every boolean threshold as gate.passed and gate.failed.

WHAT IT WILL NOT DO

Uncertainty is an output.

It never says “last surviving copy.” It can only say: “No additional holding was found across these named catalogues as of this search date.” A fragment without legible, discriminating clues may remain unidentified, and the system will abstain.

PRIOR ART

Why not a screenshot matcher or archive catalogue?

Our documented search found screenshot identifiers, archive cataloguing products, and crowdsourced identification projects, but did not find a production system combining multimodal clue extraction, live open-web historical investigation, adversarial verification, global holdings research, and claim-level provenance.

HONEST RISKS

The benchmark is easier than a genuinely unknown reel.

The evaluation fragments have known answers; real orphan material may not. Search coverage is uneven outside digitised English-language sources. Exact phrases can be reused. Human approval is mandatory because the gate measures evidence completeness, not historical truth.
